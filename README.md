• 
	1. Security and Risk Management

	• Core focus: Governance, compliance, legal regulations, and ethics.
	• Key concepts: CIA Triad (Confidentiality, Integrity, Availability), risk assessments (quantitative/qualitative), and business continuity planning (BCP).

• 
	2. Asset Security

	• Core focus: Protecting data and physical information assets throughout their lifecycle.
	• Key concepts: Data classification, ownership, handling requirements, retention, and sanitization/destruction.

3. Security Architecture and Engineering
• Core focus: Designing secure hardware, software, and infrastructure.
• Key concepts: Security models, cryptography, site/facility design, and vulnerability management of enterprise systems.

4. Communication and Network Security
• Core focus: Securing network infrastructure and data transmissions.
• Key concepts: OSI and TCP/IP models, secure routing, firewalls, VPNs, and wireless security.

5. Identity and Access Management (IAM)
• Core focus: Controlling who and what has access to enterprise resources.
• Key concepts: Identification, authentication, authorization (AAA), federation, and single sign-on (SSO).

6. Security Assessment and Testing
• Core focus: Evaluating system defenses and validating security controls.
• Key concepts: Security audits, vulnerability assessments, penetration testing, and code reviews.

7. Security Operations
• Core focus: Day-to-day security management and incident handling.
• Key concepts: Incident response, disaster recovery (DRP), logging, monitoring, and patch management.

8. Software Development Security
• Core focus: Securing applications and software lifecycles.
• Key concepts: Secure coding practices, database security, application vulnerability testing, and change management.

Vulnerabilities
A vulnerability is a weakness that can be exploited by a threat. Therefore, organizations need to regularly inspect for vulnerabilities within their systems. Some vulnerabilities include:

ProxyLogon: A pre-authenticated vulnerability that affects the Microsoft Exchange server. This means a threat actor can complete a user authentication process to deploy malicious code from a remote location.

ZeroLogon: A vulnerability in Microsoft’s Netlogon authentication protocol. An authentication protocol is a way to verify a person's identity. Netlogon is a service that ensures a user’s identity before allowing access to a website's location.

Log4Shell: Allows attackers to run Java code on someone else’s computer or leak sensitive information. It does this by enabling a remote attacker to take control of devices connected to the internet and run malicious code.

PetitPotam: Affects Windows New Technology Local Area Network (LAN) Manager (NTLM). It is a theft technique that allows a LAN-based attacker to initiate an authentication request.

Security logging and monitoring failures: Insufficient logging and monitoring capabilities that result in attackers exploiting vulnerabilities without the organization knowing it
